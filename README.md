This repository contains a collection of Bash scripts for automating repetitive system administration and development tasks. Each script is designed to streamline complex installations and other routine operations, saving time and reducing errors.

## Quick Download

You can download individual scripts using curl instead of cloning the entire repository:

### Apache

**install_apache.sh**
```bash
curl -O https://raw.githubusercontent.com/mirakib/Linux-Automation-Scripts/main/Apache/install_apache.sh
```

**ssl_apache.sh**
```bash
curl -O https://raw.githubusercontent.com/mirakib/Linux-Automation-Scripts/main/Apache/ssl_apache.sh
```
